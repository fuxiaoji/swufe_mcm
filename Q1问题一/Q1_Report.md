# 问题一：涨停后次日走势概率深度量化报告

## 1. 问题背景与目标
本研究旨在分析 A 股市场中，个股在涨停后的次一交易日其股价走势的分布规律。通过对主板和创业板/科创板（双创）的分类统计，估计其落入不同涨跌幅区间的概率，并给出 95% Wilson 置信区间。

## 2. 数据处理与清洗说明
为确保研究结果的严谨性，本研究对原始数据进行了严格的清洗：
- **数据来源**：CSMAR 数据库 A 股日交易数据。
- **样本范围**：2025 年 5 月 1 日至 2026 年 4 月 30 日。
- **清洗规则**：
    1. **剔除 ST 股**：通过涨停限制比例识别并剔除 ST 及 *ST 股票，避免极端行情干扰。
    2. **剔除新股**：剔除上市不满一年（250 个交易日）的个股，消除新股上市初期的连续涨停效应。
    3. **剔除停牌**：识别并剔除价格无波动且涨跌幅为 0 的停牌样本。
- **清洗结果**：
    - 原始样本数：$1,000,001$
    - 最终有效样本数：$294,215$ (主要剔除了大量新股阶段数据)

## 3. 数学模型建立 (符号模型)

### 3.1 涨停事件定义
设 $P_{i,t}$ 为股票 $i$ 在 $t$ 日的收盘价，$L_{i,t}$ 为其涨停价格。定义涨停指示函数 $D_{i,t}$：
$$D_{i,t} = \begin{cases} 1, & \text{if } P_{i,t} = L_{i,t} \\ 0, & \text{otherwise} \end{cases}$$

### 3.2 概率分布模型
采用频率估计法计算各区间的条件概率。设 $R_{i,t+1}$ 为股票 $i$ 在 $t+1$ 日的涨跌幅。定义样本空间 $\Omega = \{(i,t) | D_{i,t} = 1\}$。
对于任意涨跌幅区间 $[a, b)$，其条件概率估计值 $\hat{p}$ 为：
$$\hat{p} = P(a \le R_{i,t+1} < b | D_{i,t} = 1) = \frac{1}{N} \sum_{(i,t) \in \Omega} I(a \le R_{i,t+1} < b)$$
其中 $I(\cdot)$ 为指示函数，$N$ 为样本总数。

## 4. 核心量化指标 (4位精度 - 清洗后)

基于清洗后的主板样本统计结果如下：

| 涨跌幅区间 | 样本频率 ($\hat{p}$) |
| --- | --- |
| 涨停 | $0.1482$ |
| 涨幅 > 7% | $0.0795$ |
| 5% ~ 7% | $0.1084$ |
| 3% ~ 5% | $0.1412$ |
| 0% ~ 3% | $0.2095$ |
| -3% ~ 0% | $0.1924$ |
| -5% ~ -3% | $0.0685$ |
| 跌停 | $0.0112$ |

## 5. 专业图表分析

### 5.1 涨停次日收益率分布
![收益率分布](main_dist.png)

**图表介绍与解释：**
- **图表类型**：单变量分布柱状图。
- **数据维度**：X 轴为涨停次日的收益率区间分类，Y 轴为该区间出现的频率（概率）。
- **核心观察**：
    1. **惯性效应**：清洗数据后，涨停次日继续“涨停”的概率依然维持在 $0.1482$ 的高位，显示出极强的价格动量。
    2. **集中趋势**：收益率高度集中在 $-3\%$ 到 $+3\%$ 之间。
- **结论支撑**：该图表证明了在剔除新股干扰后，涨停板作为强势信号的统计有效性依然稳健。

### 5.2 多因子交叉分析 (价格分组)
![多因子分析](factor_analysis.png)

**图表介绍与解释：**
- **图表类型**：分组簇状柱形图。
- **数据维度**：X 轴代表市场分类，Y 轴代表涨停次日的平均收益率，不同颜色代表价格组。
- **核心观察**：低价股在涨停后的次日平均收益显著高于高价股，这一现象在清洗后的数据中表现得更加纯粹。
- **结论支撑**：价格因子是调节涨停溢价的关键变量。

## 6. 结论
在严格剔除 ST 和新股干扰后，主板个股在涨停后依然具有显著的惯性效应。通过 4 位精度的量化分析，我们建议投资者在参与涨停板交易时，应重点关注低价组样本。
