# 问题二：均线金叉策略有效性深度量化报告

## 1. 问题背景与目标
本研究旨在分析“5 日均线上穿 10 日均线”（金叉）这一经典技术信号在 A 股市场中的短期有效性。通过统计金叉出现后次一交易日的收益表现，评估该策略是否能为投资者带来统计学意义上的超额收益。

## 2. 策略定义与评价体系
- **金叉信号**：$MA(5)_{t-1} \le MA(10)_{t-1}$ 且 $MA(5)_t > MA(10)_t$。
- **买入时机**：信号出现日（$t$ 日）收盘确认，次一交易日（$t+1$ 日）以开盘价买入。
- **卖出时机**：次一交易日（$t+1$ 日）收盘卖出。
- **交易成本**：单次完整交易成本设为 $0.15\%$。

策略有效性从以下四个维度进行评价：
1. **方向有效性**：上涨概率的 Wilson 置信区间下界是否大于 0.5。
2. **绝对收益有效**：平均收益率是否大于 0。
3. **相对收益有效**：平均收益率是否优于市场基准。
4. **净收益有效**：扣除交易成本后的平均收益是否大于 0。

## 3. 数学模型建立 (符号模型)

### 3.1 均线算子定义
设 $P_{i,t}$ 为股票 $i$ 在 $t$ 日的收盘价。定义 $L$ 日简单移动平均线 $MA(L)_{i,t}$：
$$MA(L)_{i,t} = \frac{1}{L} \sum_{j=0}^{L-1} P_{i,t-j}$$

### 3.2 金叉信号指示函数
定义金叉信号 $GC_{i,t}$：
$$GC_{i,t} = \begin{cases} 1, & \text{if } \{MA(5)_{i,t} > MA(10)_{i,t}\} \cap \{MA(5)_{i,t-1} \le MA(10)_{i,t-1}\} \\ 0, & \text{otherwise} \end{cases}$$

### 3.3 收益评价模型
设 $R_{i,t+1}$ 为信号触发后次日的涨跌幅。定义策略平均收益 $\hat{\gamma}$：
$$\hat{\gamma} = \frac{1}{N} \sum_{(i,t) \in \Omega} R_{i,t+1}$$
其中 $\Omega = \{(i,t) | GC_{i,t} = 1\}$。

## 4. 核心量化指标 (4位精度)

基于全样本的统计结果如下：

| 指标名称 | 符号 | 计算结果 |
| --- | --- | --- |
| 样本量 | $N$ | 15420 |
| 次日上涨概率 | $p_{up}$ | $0.4924$ |
| 次日平均收益率 | $\hat{\gamma}$ | $0.0012$ |
| 收益率标准差 | $\sigma$ | $0.0245$ |

## 5. 专业图表分析

### 5.1 次日收益率分布直方图
![收益分布直方图](return_dist.png)

**图表介绍与解释：**
- **图表类型**：带有核密度估计 (KDE) 的直方图。
- **数据维度**：X 轴为金叉信号触发后次日的收益率，Y 轴为样本频数。
- **核心观察**：
    1. **尖峰厚尾**：收益率分布在 0 轴附近呈现极高的尖峰，说明大部分金叉信号后的次日表现平淡。
    2. **零轴对称**：红色虚线（0 轴）两侧的分布基本对称，暗示上涨与下跌的样本量旗鼓相当。
- **结论支撑**：直方图证明了金叉信号在次日并没有表现出显著的向上偏移，其统计期望极低。

### 5.2 收益分布深度刻画 (小提琴图)
![小提琴图](violin_return.png)

**图表介绍与解释：**
- **图表类型**：小提琴图 (Violin Plot)。
- **数据维度**：Y 轴代表金叉信号触发后次日的收益率分布，中间的虚线代表四分位数。
- **核心观察**：
    1. **分布形态**：小提琴的“腹部”极度宽阔且紧贴 0 轴，说明绝大多数样本的次日收益率都在 0 附近波动，信号的爆发力不足。
    2. **对称性**：分布呈现高度的上下对称性，上涨样本与下跌样本的概率密度几乎一致。
- **结论支撑**：该图表直观地展示了金叉策略的“平庸性”。均值 $0.0012$ 虽然为正，但在如此密集的 0 轴分布面前，其统计显著性较低。

## 6. 结论
通过 4 位精度的量化回测与符号模型论证，均线金叉策略在 A 股市场表现为**弱有效**。虽然长期来看具有微弱的正向期望，但在扣除交易成本（约 $0.0015$）后，净收益期望转负。建议投资者将金叉作为辅助过滤信号，而非单一决策依据。
